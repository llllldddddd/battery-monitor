# Монитор батареи

Веб-страница для просмотра данных LiFePO4-батареи по Bluetooth прямо из браузера (Chrome на Android или компьютере).

Открыть: https://llllldddddd.github.io/battery-monitor/

- Заряд, напряжение, ток, мощность, ячейки, температуры — обновление каждые 2 секунды.
- Графики: пока страница подключена, показания записываются каждые 10 секунд и хранятся в браузере 30 дней. Выгрузка в CSV.
- Данные никуда не отправляются: телефон читает их напрямую с батареи.

Протокол: Bluetooth-модуль Nations (сервис `00002760-08c2-11e1-9073-0e8ac72e1001`), внутри Modbus RTU, адрес 1, функция 03.
