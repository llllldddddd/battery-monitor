# Монитор батареи

Показания LiFePO4-батареи по Bluetooth: веб-страница, приложение для Mac и приложение для Android.
Все три работают без интернета — это важно, когда отключили свет и роутер тоже без питания.

- Заряд, напряжение, ток, мощность, ячейки, температуры — обновление каждые 2 секунды.
- Графики: пока программа подключена, показания записываются каждые 10 секунд и хранятся на устройстве 30 дней. Выгрузка в CSV.
- Данные никуда не отправляются: устройство читает их напрямую с батареи.

## Веб-страница

https://llllldddddd.github.io/battery-monitor/ — Chrome на Android или компьютере.
После первого открытия страница сохраняется в браузере и открывается без интернета.
В Chrome её можно установить как приложение: меню → «Установить приложение» / «Добавить на главный экран».

## Mac

```
mac/build.sh install
```

Нужны только Xcode Command Line Tools. Приложение «Монитор батареи» появится в «Программах».
При первом подключении macOS спросит разрешение на Bluetooth. Запоминает батарею и при запуске подключается к ней сама,
пропала связь — переподключается, пока батарея не вернётся. Пока подключено, Mac не уходит в сон (экран гаснет как обычно).

## Android

```
cd android && ./gradlew assembleRelease
```

Готовый файл: `android/app/build/outputs/apk/release/app-release.apk` (подписан отладочным ключом, ставится напрямую,
нужно разрешить установку из неизвестных источников). Android 7 и новее. Нужна JDK 17–21.
Как и страница, держит экран включённым, пока подключено: иначе Android останавливает приложение.

## Как устроено

Интерфейс один на всех: `index.html`. В приложениях нет Web Bluetooth, поэтому `app/bridge.js` подменяет
`navigator.bluetooth` и передаёт команды нативной части: `mac/main.swift` (CoreBluetooth) и
`android/.../MainActivity.java` (Android BLE API).

Протокол: Bluetooth-модуль Nations (сервис `00002760-08c2-11e1-9073-0e8ac72e1001`), внутри Modbus RTU, адрес 1, функция 03.
